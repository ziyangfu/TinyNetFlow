eclipse score 开源项目，采用了一种基于模板的“对象缝合”机制，用于在生产代码和测试代码之间解耦，支持注入测试用例中的 mock 对象。

ObjectSeam 类模板：

提供一个可继承的基类，允许为某个对象类型 Object 定义“测试替身”。
支持通过 set_testing_instance() 注入测试对象指针。
使用静态方法 select_instance() 在运行时选择实际使用的对象（测试或生产）。
内部使用静态局部变量保存测试实例指针，实现单例风格的替换。
MockGuard 类模板：

RAII 风格的辅助类，自动注册 mock 实例为当前测试实例。
构造时调用 set_testing_instance() 注册 mock。
析构时调用 restore_instance() 恢复原始状态。
提供类似指针的访问接口（* 和 ->），方便访问内部 mock 对象。
